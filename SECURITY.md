# Security Policy

## Reporting a vulnerability

Please report security issues privately to Bhupesh Cholake (https://github.com/RealBhupesh).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/RealBhupesh/resend-sdk/issues

## Scope

This policy applies to the generated Bhupesh Cholake SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Resend public API, generated by
Bhupesh Cholake. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
